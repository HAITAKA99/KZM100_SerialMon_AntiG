## 1. はじめに・特徴

「かざみんリアルタイムモニター」は、PCやスマートフォンのブラウザから直接「かざみん」とシリアル通信を行い、計測データをリアルタイムにダッシュボード表示・記録するWebアプリケーションです。

### 主な特徴
- **専用ソフトのインストール不要**: ブラウザ（Google Chrome / Microsoft Edge など）を開くだけで即座に動作。
- **リッチな計測コンソール**: 方位盤風向計、ダイアル風速計、丸形温度計、統合時系列グラフを1画面に集約。
- **最長7日間のデータ自動保持**: ブラウザ内データベース（IndexedDB）に自動蓄積。ブラウザを閉じてもデータは保持されます。
- **ワンクリック CSV出力**: Excel等で解析可能なBOM付きUTF-8 CSVファイルを即座にダウンロード可能。
- **PWA（Progressive Web Apps）& オフライン対応**: インターネット未接続の現場環境や山間部でも安定動作。

## 2. 動作環境・事前準備

### 推奨ブラウザ
ブラウザからシリアルポートを制御する **Web Serial API** をサポートした環境が必要です。

| プラットフォーム | 対応ブラウザ | 動作可否 | 備考 |
| :--- | :--- | :---: | :--- |
| **Windows 10 / 11** | Google Chrome, Microsoft Edge, Opera, Brave | **◎ 推奨** | 最新版をご利用ください |
| **macOS** | Google Chrome, Microsoft Edge, Opera, Brave | **◎ 推奨** | `/dev/tty.*` を認識可能 |
| **Linux / ChromeOS** | Google Chrome, Chromium, Edge | **○ 対応** | `dialout` グループ権限等が必要な場合あり |

| **iOS / iPadOS (Safari)** | Safari, Chrome for iOS | **× 非対応** | Web Serial API 未サポート（デモのみ可） |

### 機器の準備
1. 超音波風向風速計 かざみん（KZM100A または KZM100LR）
2. 電源供給（かざみん規定の電源配線）
3. USBシリアル変換ケーブル（PCと接続用）

## 3. クイックスタート（使い方 3ステップ）

```
[かざみん] ──(USBシリアル)──> [パソコン/端末] ──(ブラウザで開く)──> [リアルタイムモニター]
```

### ステップ 1: かざみんと端末を接続する
かざみんに電源を入れ、USBシリアル変換ケーブルをパソコンまたはAndroid端末のUSBポートに挿入します。

### ステップ 2: モニター画面を開く
ブラウザ（Chrome または Edge）で `index.html`（または公開URL）を開きます。

### ステップ 3: 「接続」ボタンをクリックしてCOMポートを選択する
1. 画面右上の **「接続」** ボタンをクリックします。
2. ブラウザ画面中央にシリアルポート選択ダイアログが表示されます。
3. かざみんが接続されているCOMポート（例: `USB Serial Port (COM3)` や `CP2102 USB to UART Bridge`）を選択し、**「接続」** を押します。
4. ステータスが **「● 接続中」** に変わり、1秒ごとに最新データが反映され始めます。

> **💡 実機がお手元にない場合**  
> 画面上部の **「デモ」** ボタンを押すと、シミュレーションデータが自動生成され、すべてのメーターやグラフの動きを体験できます。

## 4. 画面と機能の詳細解説

### 4-1. ヘッダー部（接続管理・ステータス・時計）
- **ステータス表示**:
  - `未接続`（灰色）: ポートが開かれていない待機状態。
  - `接続中`（水色）: 正常にシリアルパケットを受信中。
  - `デモ中`（黄色）: 内部デモシミュレータ動作中。
- **接続 / 切断ボタン**: シリアルポートのオープン・解放。
- **デモボタン**: シミュレーションモードのON/OFF。
- **デジタル時計**: JST 24時間表示のデジタルクロック。

---

### 4-2. リアルタイムメーター群（風向・風速・温度計）

#### 🧭 風向メーター (Wind Direction)
- **シェブロン型大型針**: 風向（風が吹いてくる方角）を指し示します。
- **最短回転アニメーション**: 例えば 350° から 10° への遷移時、反対回りに大回りせず 20° の最短距離で滑らかに回転します。
- **方位角表示**: 16方位（N, NNE, NE ...）および角度（0°〜359°）を数値表示。

#### 💨 風速メーター (Wind Speed)
- **カラーグラデーション円弧**: 0 m/s（青・緑）から強風（黄・赤）まで視覚的に把握。
- **スケール自動連動**: グラフの風速スケール（5 / 10 / 20 / 30 m/s）と連動してメーターの最大目盛りが自動切り替えされます。
- **大型デジタル表示**: `0.0 m/s` 単位で小数点第1位まで表示。

#### 🌡️ 温度計 (Temperature)
- **氷点・適温インジケーター**: **0℃（氷点）** と **25℃（快適適温）** の位置に専用マーカーを配置。
- **摂氏（℃）/ 華氏（°F）併記**: メインの摂氏表示の下に自動計算された華氏温度を小さく表示。
- **レンジ連動**: 標準（-10〜+50℃）/ 広域（-20〜+65℃）と連動。

> **⚠️ 計測エラー（99.9 m/s）の検知**  
> かざみんが計測エラーを検知すると風速 `99.9 m/s` が送信されます。モニターはこれを瞬時に判別し、メーターに赤色の **`ERROR`** バッジを表示して針を警告色に切り替えます。

### 4-3. 統合時系列グラフ（Canvas描画・集約仕様）

HTML5 Canvas を使用した軽量・高速なリアルタイム統合グラフです。

| 系列 | グラフタイプ | 対応軸 | 色 |
| :--- | :--- | :--- | :--- |
| **気温** | 平滑化ライン | 左側 Y軸 (℃) | スカイブルー |
| **風速** | 平滑化ライン | 右側 外側Y軸 (m/s) | エメラルドグリーン |
| **風向** | 散布図 (点プロット) | 右側 内側Y軸 (0〜360°) | ゴールド |

#### 時間軸スケールと集約（平均化）ルール
グラフ上のプロット数は **常に600点固定** です。右端が最新の受信データ、左側が過去データとなります。

- **10分間 (10m)**: 1秒毎のデータをそのまま600点描画（\(10 \times 60 = 600\)点）。
- **1時間 (1h)**: 6秒間隔でスクロール。直近6秒間の平均値を1点としてプロット。
- **6時間 (6h)**: 36秒間隔でスクロール。直近36秒間の平均値。
- **24時間 (24h)**: 144秒間隔でスクロール。直近144秒間の平均値。
- **7日間 (7d)**: 1008秒間隔（約16.8分）でスクロール。直近1008秒間の平均値。

> **📐 高度な平均化処理**  
> - **風向の平均**: 0°と360°の境界を正しく処理するため、三角関数を用いた **ベクトル平均**（\(\text{atan2}(\sum \sin, \sum \cos)\)）で算出されます。  
> - **エラーデータの除外**: 計測エラー（99.9 m/s）発生時の風速・風向データは、平均値計算の母集団から自動除外されます。

### 4-4. 受信コンソール（RAWパケットログ）
- 最新 **200件** の受信ログを等幅フォントで一覧表示。
- カラム構成: `受信日時` / `風速 [m/s]` / `風向 [deg]` / `気温 [℃]` / `状態` / `RAWパケット`
- **自動スクロール**: 最新行へ自動追従（画面上のチェックボックスで一時固定可能）。
- **クリアボタン**: 画面上のコンソールログのみを即時消去。

---

### 4-5. データ自動保存とCSV出力

#### IndexedDB への自動永続化
受信した有効な測定パケットは、ブラウザ内の高速データベース **IndexedDB** に1秒ごとに自動保存されます。ブラウザのタブを閉じたりPCを再起動しても、過去7日間のデータは消去されません。

#### CSVエクスポート手順
1. 画面下部の **「CSVダウンロード」** ボタンをクリックします。
2. `kazamin_log_YYYYMMDD_HHMMSS.csv` というファイル名でダウンロードが実行されます。
3. **BOM付き UTF-8** 形式のため、Microsoft Excel でダブルクリックするだけで文字化けせずに開けます。

#### 7日間自動パージ & 手動クリア
- **自動パージ**: 起動時および1時間ごとに、保存日時が **7日以前（168時間超）** の古いレコードを自動削除し、ブラウザの容量枯渇を防ぎます。
- **履歴クリア**: 「履歴クリア」ボタンを押すと、IndexedDB に保存されたすべての測定データを初期化できます。

## 5. 応用機能と便利なTips

1. **複数台の「かざみん」を同時に監視する**  
   ブラウザのタブを2つ開き、それぞれのタブで異なるCOMポート（例: COM3 と COM4）に接続することで、同一PC上で複数のかざみんを並行監視できます。
2. **デスクトップアプリとして利用（PWAインストール）**  
   Chrome / Edge のアドレスバー右端に表示される「インストール」アイコンを押すと、独立したウィンドウで起動するデスクトップアプリとしてご利用いただけます。
3. **起動時自動デモURL**  
   `index.html?demo=true` をブックマークしておくと、アクセス時に自動でデモモードが開始されます（展示会やデモ用途に便利です）。

## 6. よくある質問とトラブルシューティング (FAQ)

### Q1. 「お使いのブラウザはWeb Serial APIに対応していません」と警告が出る
- **原因**: 非対応のブラウザ（Firefox、Safari、iOS端末等）で開いている可能性があります。
- **対処**: Windows / Mac / Android 版の **Google Chrome** または **Microsoft Edge** をご利用ください。

### Q2. 「接続」を押してもかざみんのポート名が見つからない
- **原因**: USBケーブルの接触不良、またはシリアル変換ICのドライバ未導入。
- **対処**:
  1. USBケーブルを挿し直してください。
  2. Windowsの「デバイス マネージャー」を開き、「ポート (COM と LPT)」にデバイスが認識されているか確認してください（黄色い「！」マークがある場合はメーカー提供のVCPドライバをインストールしてください）。

### Q3. 「接続中」になるがメーターが動かない・データが流れてこない
- **原因**: かざみんの電源未投入、配線のTX/RX逆接続、または他ソフトによるポート占有。
- **対処**:
  1. かざみんの電源が規定電圧で入っているか確認してください。
  2. Tera Term や Arduino IDE などの他のシリアル通信ソフトが起動している場合は終了してください（1つのCOMポートは同時に1つのアプリしか開けません）。

### Q4. 風速が「99.9 m/s」になり「ERROR」と表示される
- **原因**: かざみんの超音波トランスデューサ間に雨滴、雪、虫、落ち葉等の異物があるか、超音波の乱れが発生しています。
- **対処**: センサーヘッド周辺の異物を取り除いてください。

## 7. シリアル通信仕様・パケット仕様

### 通信パラメータ
| 項目 | 設定値 |
| :--- | :--- |
| **通信方式** | RS-232C / 非同期調歩同期式シリアル (Web Serial API) |
| **ボーレート (Baud Rate)** | `9600 bps` (固定) |
| **データ長 (Data Bits)** | `8 bit` |
| **パリティ (Parity)** | `なし (None)` |
| **ストップビット (Stop Bit)** | `1 bit` |
| **フロー制御 (Flow Control)** | `なし (None)` |
| **送信周期** | `1.0 秒` (かざみんより自律送信) |

### パケットフォーマット
固定桁数のアスキー文字列フォーマットです。末尾は `[CR][LF]`（`\r\n`）。

```
00.0[m/s],000,+00.0\r\n
  │         │    └─ 気温: -20.0 〜 +65.0 [℃] (符号付き固定桁)
  │         └────── 風向: 000 〜 359 [度] (3桁固定)
  └──────────────── 風速: 00.0 〜 99.9 [m/s] (99.9はエラー)
```

**受信例:**
- `04.2[m/s],085,+19.4` : 風速 4.2m/s, 風向 85°(東微北), 気温 +19.4℃
- `99.9[m/s],000,+22.0` : 計測エラー（風速 99.9m/s）
