1. はじめに

「かざみんリアルタイムモニター」は、超音波風向風速計「かざみん (KZM100A / KZM100LR)」で計測された風速・風向・気温データを、ウェブブラウザ上でリアルタイムに可視化・記録するためのWebアプリケーションです。

⚡ インストール不要

専用ソフトのインストールは不要です。ブラウザの Web Serial API を使用し、PCやスマホから直接シリアル通信を行います。

📊 リッチなダッシュボード

直感的なダイアルメーター（風向・風速・気温）と、過去7日間まで追尾できる統合時系列グラフを装備しています。

💾 7日間データ自動保持 & CSV出力

受信データはブラウザ内の IndexedDB に自動蓄積され、ワンクリックで Excel 対応の CSV ファイルとしてダウンロード可能です。

🌐 オフライン・PWA対応

Service Worker による PWA（Progressive Web App）に対応しており、山間部や電波の届かないオフライン環境でも動作します。

2. 動作環境と準備

推奨動作環境

ブラウザがシリアルポートと直接通信する Web Serial API をサポートしている必要があります。

プラットフォーム 対応ブラウザ 備考
Windows / Mac / Linux / ChromeOS Google Chrome, Microsoft Edge, Opera, Brave 推奨。最新バージョンをご利用ください。
Android Google Chrome (OTGケーブル経由) USB-OTG 接続にてシリアル変換チップが認識可能。
iOS / iPadOS (Safari) 非対応 (Web Serial API 未サポート) ※デモモードの閲覧のみ可能です。
ℹ️
通信ポートの準備: かざみんをPCにUSBシリアル変換ケーブル等で接続し、OSのデバイスマネージャーでCOMポート（Mac/Linuxでは /dev/tty.*）が正常に認識されていることをご確認ください。

3. クイックスタート (使い方)

わずか3ステップで計測モニタリングを開始できます。

1

かざみんを端末に接続

超音波風向風速計「かざみん」の電源を入れ、USBシリアルケーブルでパソコンまたはAndroid端末に接続します。

2

ブラウザでモニター画面を開く

Google Chrome または Microsoft Edge で本モニター（index.html）を開きます。

3

「接続」ボタンを押してポートを選択

画面上部の 接続 ボタンをクリックします。ブラウザのポート選択ダイアログが表示されるので、かざみんが接続されているシリアルポート（例: USB Serial Port (COM3)）を選択して「接続」を押します。

💡
実機がない場合: 画面上部の デモ ボタンをクリックすると、仮想的な風速・風向・気温データを生成するシミュレータが起動し、すべての表示機能をお試しいただけます。

4. 画面・機能の詳細解説

① ヘッダー・接続制御

画面最上部にはシステムの稼働状況と操作ボタンが集約されています。

  • ステータスインジケーター:
    • ● 未接続: シリアルポート未オープン状態
    • ● 接続中: 正常にシリアル通信を受信中
    • ● デモ中: 内部シミュレーター稼働中
  • 接続 / 切断ボタン: シリアルポートのオープン／クローズを切り替えます。
  • デモボタン: デモモードの開始・停止を切り替えます。
  • デジタル時計: 現在時刻を24時間形式で正確に表示します。

② リアルタイムメーター群

最新1秒の測定値を直感的に把握できる3連メーターです。

🧭 風向メーター (Wind Direction)

  • シェブロン型大型針: 風が吹いてくる方位を大きく明快に指し示します。
  • 最短回転補間: 350°から10°に変化する際も反対回りせず、最短角度でスムーズに回転します。
  • 16方位 + 角度表示: 北 (0°/N)、東 (90°/E)、南 (180°/S)、西 (270°/W) と詳細度数。

💨 風速メーター (Wind Speed)

  • ダイナミックスケール: グラフの選択スケール（5 / 10 / 20 / 30 m/s）と自動連動。
  • カラーグラデーション: 微風（シアン・緑）から強風（黄・赤）へ視覚的に警告。
  • デジタル数値: 小数点第1位（0.0 m/s）まで大型フォントで表示。

🌡️ 温度計 (Temperature)

  • 重要温度マーカー: 氷点（0℃）と適温（25℃）の位置に専用インジケーターを配置。
  • 摂氏・華氏の併記: メインの摂氏（℃）に加えて華氏（°F）も自動計算して小さく表示。
  • 連動レンジ: 標準（-10〜+50℃）と広域（-20〜+65℃）をワンタッチ切替可能。
⚠️
計測エラー表示（99.9 m/s）: かざみんが超音波の乱れや障害物等で計測エラーを検知すると、風速 99.9 m/s が送信されます。本モニターはこれを自動検知し、メーターに ERROR バッジを表示して針を赤色警告状態にします。

③ 統合時系列グラフ

HTML5 高速 Canvas レンダリングにより、風速・風向・気温の3要素を1画面に統合してプロットします。

系列名 チャート形式 対応軸 描画色
気温 (Temperature) 滑らかなスプライン曲線 左側 Y軸 (℃) ■ シアン / スカイブルー
風速 (Wind Speed) 滑らかなスプライン曲線 右側 外側Y軸 (m/s) ■ エメラルドグリーン
風向 (Wind Direction) 散布図 (ドットプロット) 右側 内側Y軸 (0〜360°) ● ゴールド / アンバー

時間スケールとデータ集約ルール

グラフ上のプロット点数は 常に600点固定 です。右端が最新の受信値、左に向かって過去データとなります。

  • 10分間 (10m): 1秒ごとの生データを600秒分そのまま全プロット。
  • 1時間 (1h): 6秒間隔（6秒間の平均値を1点としてスクロール）。
  • 6時間 (6h): 36秒間隔（36秒間の平均値）。
  • 24時間 (24h): 144秒間隔（144秒間の平均値）。
  • 7日間 (7d): 1008秒間隔（1008秒間の平均値）。
📐
科学的な平均化処理: 風向の平均化には単純な算術平均ではなく ベクトル平均（三角関数による角度合成） を採用しており、北（359°と1°）の境界付近でも正しい平均風向が算出されます。また、エラーデータ（99.9m/s）は平均化の母集団から自動除外されます。

④ 受信コンソール

かざみんから送られてくるテキストパケットをリアルタイムにログ表示します。

  • 最新200件保持: メモリを圧迫しないよう最大200件のリングバッファで管理。
  • 等幅フォーマット: タイムスタンプ、風速、風向、気温、RAW文字列が綺麗に整列。
  • 自動スクロール: 新しいデータを受信するたびに最下部に自動追従（チェックボックスで解除可能）。
  • エラーハイライト: エラーパケット行は赤色背景で強調されます。

⑤ データ保存とCSV出力

測定データはブラウザ内のセキュアなデータベース（IndexedDB）にリアルタイムで自動保存されます。

CSVエクスポート

画面下部の CSVダウンロード ボタンを押すと、IndexedDB に蓄積されている全測定ログ（最大7日間分）がCSVファイルとして一括出力されます。

  • ファイル名: kazamin_log_YYYYMMDD_HHMMSS.csv
  • 文字コード: BOM付き UTF-8（Microsoft Excel でそのまま開いても日本語が文字化けしません）

データ保持期間と自動パージ

ブラウザのストレージ容量枯渇を防ぐため、7日以上経過した過去データは起動時および1時間ごとに自動消去されます。全データを手動でリセットしたい場合は「履歴クリア」ボタンを使用します。

5. 便利な応用機能・Tips

🖥️ 複数台の「かざみん」同時監視

ブラウザのタブを複数開くことで、ポートの異なる複数台のかざみんを1台のPCで同時にリアルタイムモニタリングできます。

📱 PWA アプリとしてインストール

ChromeやEdgeのURLバーにある「インストール」アイコンを押すと、デスクトップやスマホのホーム画面に専用アプリとして登録できます。

🔗 URLパラメータによる自動デモ

URLの末尾に ?demo=true を付けて開くと、起動と同時に自動でデモモードが開始されます（展示やテストに便利です）。

6. よくある質問・トラブル解決

「お使いのブラウザはWeb Serial APIに対応していません」と表示される
Web Serial API に対応したブラウザ（Windows/Mac/Linux版の Google Chrome、Microsoft Edge、または Android版 Chrome）をご利用ください。iPhone / iPad（Safari）や Firefox はブラウザの仕様上シリアル通信に対応していません。
「接続」を押してもポート選択一覧にかざみんが表示されない
USBシリアルケーブルが正しく挿入されているか、またOSのシリアルドライバ（FTDI、CP210x、CH340など）がインストールされているかご確認ください。Windowsの場合はデバイスマネージャーの「ポート (COM と LPT)」を確認してください。
接続できたがデータを受信しない（メーターが動かない）
かざみん本体の電源が入っているか、配線（TX/RX）が正しく接続されているかご確認ください。また、他のシリアル通信ソフト（Tera Term 等）で既に同じCOMポートを開いていると排他制御により接続できません。他のソフトを終了してから再度お試しください。
風速が「99.9 m/s」になり「ERROR」と表示される
かざみんの超音波トランスデューサ間に雨滴、雪、虫、鳥などの異物が挟まっている場合や、極端な突風・超音波障害によって計測不能になると出力されます。センサーヘッド周辺の障害物を取り除いてください。
PCを再起動したりブラウザを閉じるとデータは消えますか？
データはブラウザの IndexedDB に永続保存されているため、ブラウザを閉じたりPCを再起動しても過去7日間のログは消えません。再度ページを開けばグラフも自動復元されます（ブラウザの「閲覧履歴とCookieの完全消去」を実行した場合を除く）。
